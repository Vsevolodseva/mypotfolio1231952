# Портфолио: Разработка Telegram-ботов на Python (aiogram 3.x)

Привет! Я занимаюсь разработкой надежных и быстрых Telegram-ботов для бизнеса, инфобизнеса и автоматизации процессов. Использую современный асинхронный стек.

## 🛠 Мой стек технологий
- **Язык:** Python 3.11
- **Фреймворк:** aiogram 3.x (Asynchronous Telegram Bot API)
- **Базы данных:** SQLite, PostgreSQL
- **Архитектура:** СУБД, конечные автоматы (FSM), интеграция платежных систем (Telegram Stars)

## 📁 Примеры разработанных решений (Шаблоны в репозитории)
1. **Бот-визитка / Сборщик заявок** — Автоматизирует первичный контакт с клиентом, отправляет структурированные лиды в админ-панель.
2. **Бот «Закрытый VIP-клуб»** — Генерирует одноразовые инвайт-ссылки в приватный канал строго после успешной оплаты через Telegram Stars.
3. **Бот-Генератор лидов (Лид-магнит)** — Проверяет подписку пользователя на целевой канал перед выдачей бесплатного инфопродукта/подарка.
